# Checklist del Owner

Responsabilidades mínimas del owner de un proyecto.

## Diario

- [ ] Revisar Slack del proyecto
- [ ] Responder mensajes del cliente en <24h
- [ ] Verificar que no hay blockers sin atender

## Semanal

### Comunicación
- [ ] Organizar y liderar weekly interno
- [ ] Organizar y liderar weekly con cliente
- [ ] Ser punto de contacto principal

### Reportes
- [ ] Actualizar `weekly-notes.md`
- [ ] Preparar reporte semanal para cliente
- [ ] Enviar status update

### Seguimiento
- [ ] Verificar Linear actualizado
- [ ] Conocer obligaciones contractuales
- [ ] Saber qué se ha entregado y qué falta
- [ ] Verificar si estamos on track con fechas

## Mensual

- [ ] Revisar scope vs contrato
- [ ] Verificar facturación al día
- [ ] Evaluar si proyecto debe cambiar de tier
- [ ] Feedback con el equipo

## Antes de Vacaciones/Ausencia

- [ ] Definir backup temporal
- [ ] Informar al cliente
- [ ] Briefing al backup
- [ ] Documentar estado actual

## Red Flags a Escalar

Escalar inmediatamente a socios si:
- Cliente no responde en >1 semana
- Blocker sin solución en >3 días
- Riesgo de no cumplir deadline
- Conflicto con cliente
- Cambio de scope significativo
- Problema de facturación/pago
