# Brand Guidelines

Guía de marca para documentos corporativos.

## Logo

### Uso Principal
- Logo horizontal para headers de documentos
- Tamaño mínimo: 100px de ancho
- Espacio de respeto: altura de la "M" alrededor

### Variantes
| Variante | Uso |
|----------|-----|
| Color sobre blanco | Default |
| Blanco sobre oscuro | Fondos oscuros |
| Negro monocromático | Impresión B/N |

### No hacer
- No estirar o distorsionar
- No cambiar colores
- No agregar efectos (sombras, brillos)
- No rotar

## Documentos

### Propuestas Comerciales

**Estructura de página:**
```
┌────────────────────────────────┐
│ [Logo]            Fecha: XX/XX │  ← Header
├────────────────────────────────┤
│                                │
│         [Contenido]            │  ← Body (márgenes 2.5cm)
│                                │
├────────────────────────────────┤
│ www.munolabs.com      Pág X/Y  │  ← Footer
└────────────────────────────────┘
```

**Colores en propuestas:**
- Títulos de sección: Azul #0000FF
- Texto: Negro o Gris 900
- Destacados: Azul sobre fondo gris claro
- Precios: Negro, bold, alineado derecha

### Contratos

**Diferencias con propuestas:**
- Más formal, menos color
- Numeración de cláusulas: PRIMERA, SEGUNDA, etc.
- Sin imágenes decorativas
- Espacios para firmas al final

## Presentaciones

### Slides
- Fondo: Blanco o Gris 50
- Títulos: Azul o Negro
- Texto: Máximo 6 bullets por slide
- Imágenes: Alta resolución, con respiración

### Diagramas
- Líneas: 2px, colores de marca
- Cajas: Bordes redondeados (8px)
- Flechas: Con punta, mismo color que líneas

## Emails Formales

- Saludo: "Estimado/a [Nombre],"
- Cierre: "Saludos cordiales," o "Atentamente,"
- Firma: Nombre + Cargo + Empresa + Teléfono
- No usar colores ni formatos elaborados en el cuerpo
