# Taxonomía de Tags

## Categorías de Contenido

### Desarrollo
| Tag | Descripción |
|-----|-------------|
| `Code` | Código fuente, snippets |
| `Terminal` | Línea de comandos, logs |
| `Error` | Mensajes de error, excepciones |
| `API` | Respuestas API, Postman, curl |
| `Database` | Queries, schemas, datos |
| `Git` | Commits, PRs, branches |

### Diseño
| Tag | Descripción |
|-----|-------------|
| `UI` | Interfaces de usuario |
| `Wireframe` | Bocetos, wireframes |
| `Mockup` | Diseños de alta fidelidad |
| `Component` | Componentes aislados |
| `Icon` | Iconos, assets gráficos |

### Productividad
| Tag | Descripción |
|-----|-------------|
| `Email` | Correos electrónicos |
| `Chat` | Mensajes de chat |
| `Document` | Docs, PDFs, texto |
| `Spreadsheet` | Tablas, Excel, Sheets |
| `Presentation` | Slides, presentaciones |
| `Calendar` | Eventos, calendarios |
| `Task` | Tareas, tickets |

### Análisis
| Tag | Descripción |
|-----|-------------|
| `Chart` | Gráficos, visualizaciones |
| `Dashboard` | Dashboards, métricas |
| `Analytics` | Data analytics |
| `Report` | Reportes |

### Comunicación
| Tag | Descripción |
|-----|-------------|
| `Meeting` | Videollamadas, calls |
| `Feedback` | Reviews, comentarios |
| `Discussion` | Threads, discusiones |
